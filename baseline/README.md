# The baseline

`crt-glass.frag` is the glass shader the omarchy-crt plugin ships, copied
unmodified from https://github.com/parker-brown-family/omarchy-crt at commit
`bcfd334` (MIT, same author). It is here so the benchmark's "existing" path
measures the real thing on any checkout. It is a pinned copy for measurement,
not a fork: the plugin's own repository is where that shader changes.
